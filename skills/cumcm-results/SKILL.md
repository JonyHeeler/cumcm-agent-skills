# 结果展示

本技能辅助 MathModelAgent 的 3coding-visual、5writing 阶段；沿用旧流程的调度、阶段边界、文件交接、章节和验收要求，建模/编码阶段的写作建议先进入阶段报告，正式正文由 `5writing` 落实。也可独立审改已有论文的对应内容，保持现有结构，不启动整套流程。

读 [结果决策](references/decisions.md)，先定位真实输出、情景定义、单位和求解/验证状态。

1. 逐问确定读者要找的答案：数值、关系式、类别、方案或不可行条件。关键答案在正文可找到，不只指向附件。
2. 单个答案用句子，精确方案或多维比较用表，趋势/分布/误差用图。选一种主要呈现方式，避免无信息增益的重复。
3. 交代比较条件，指出关键观察，说明证据允许的解释，最后回应设问。无需固定为五句话。
4. 图表后写它支持的具体论点，而非“如图所示”；区分直接观察、模型解释与未证实的原因。
5. 比较方案时统一数据、约束和预算，报告有意义的差值及单位；核查百分比基准和小数位数。启发式解不改称理论最优。

交付答案及图表说明，并维护内部“数值→输出文件/字段/情景”的追溯。发现缺失结果或数字冲突则回查计算，不能靠改写掩盖。
