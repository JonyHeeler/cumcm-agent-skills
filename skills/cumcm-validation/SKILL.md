# 模型与结果验证

读 [风险到验证](references/decisions.md)。先明确要支持的具体主张，再决定实验；不要求每个模型都做同一套检验。

1. 区分模型假设风险、数据/估计误差、算法数值误差、不可行风险与外推风险。
2. 选择能够暴露主要失败方式的检验，预先写明比较基准、范围、指标、容差和失败后处理。范围与容差来自题目精度、测量误差或实际需求，不随结果美化。
3. 实际执行：约束回代、全过程检查、解析特例/网格细化、匹配数据结构的留出、独立情景/参数扰动等按需选用。
4. 记录成功和失败结果，说明证据支持到哪里。多次搜索一致不证明全局最优，拟合好不证明泛化，有限扰动不证明全域稳定。
5. 验证失败则定位到数据、模型或求解根因并修正；改动后重检受影响结论，不把失败藏进“未来改进”。

输出“主张—检验—结果—边界”的证据记录和可写入论文的分析。未运行的检验写为计划；不能因缺少真值就宣布模型正确。
