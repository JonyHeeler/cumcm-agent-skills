# 模型与结果验证

本技能辅助 MathModelAgent 的 2analysis-modeling、3coding-visual、6verity 阶段；沿用旧流程的调度、阶段边界、文件交接、章节和验收要求，建模/编码阶段的写作建议先进入阶段报告，正式正文由 `5writing` 落实。也可独立审改已有论文的对应内容，保持现有结构，不启动整套流程。

读 [风险到验证](references/decisions.md)。先明确要支持的具体主张，再决定实验。常见竞赛题通常需要敏感性分析，应主动识别关键参数/假设并安排检验；确无适用对象时说明理由，不机械补做。

1. 区分模型假设风险、数据/估计误差、算法数值误差、不可行风险与外推风险。
2. 选择能够暴露主要失败方式的检验，预先写明比较基准、范围、指标、容差和失败后处理。优先采用题目明确的精度；题目未说明时，以步长/网格减半后关键结果相对变化小于 1% 作为默认数值检查选项，标明这是默认值。测量误差或实际需求要求更严时收紧；近零结果改用有依据的绝对容差，不随结果美化。
3. 实际执行：约束回代、全过程检查、解析特例/网格细化、匹配数据结构的留出、独立情景/参数扰动等按需选用。
4. 记录成功和失败结果，说明证据支持到哪里。启发式可直接用于建模求解，但多次搜索一致不证明全局最优；此处不采用旧共享规范中稳定性足以支持全局最优的例外。拟合好不证明泛化，有限扰动不证明全域稳定。
5. 回归诊断沿用旧技能的验收口径，具体见参考文件；不以本技能的一般性建议跳过旧检查。
6. 验证失败则定位到数据、模型或求解根因并修正；改动后重检受影响结论，不把失败藏进“未来改进”。

输出“主张—检验—结果—边界”的证据记录和可写入论文的分析。未运行的检验写为计划；不能因缺少真值就宣布模型正确。
