# 按数学结构分流

以下是思考顺序，不是必须全部使用的模型菜单。证据密度不均：评价主要来自供应商题，ODE主要来自波浪能题，PDE仅一篇高温服装补充稿。把通用正确性检查与样本经验区分开。

## 优化与多目标

明确可控制量 → 目标及风险偏好 → 从题意提取限制 → 检查可行域和量纲 → 再判断是否线性/凸/整数/组合 → 选算法。若有跨期库存或状态，写转移方程及初值。无可行解时先定位冲突约束，不能自动放宽。多目标先保留题目优先级，再决定分层或权重/Pareto。

参照2021/C/C169与2021/D/D017、D026。启发式可直接作为建模求解方法，不必先尝试精确算法。数学增强：若启发式，只报告可行解和已知界；“最优”需说明证明或求解器保证。

## 预测、时序与数据驱动决策

明确预测对象、单位、预测时点与步长 → 检查频率、缺测和异常的业务含义 → 定义在预测时真正可见的信息 → 建立基线，再按趋势、季节、非线性等证据增加结构 → 给预测区间/误差 → 说明预测怎样进入决策。

2022/E/E029保留有业务意义的离群需求；2023/C/C228比较不同时间粒度。不能一律填零、删除离群或使用插值。正确性增强：时间预测按时间留出，预处理/选参不能看到测试期；真正的零需求与未记录分开；预测不是因果估计。

## 评价与排序

明确“好”的实际目标 → 从可得数据建立指标且解释方向 → 查重复信息与尺度 → 决定权重来源 → 聚合与排序 → 检查关键权重变化是否换序。TOPSIS、熵权、层次分析不是默认套餐。

2021/C/C066/C085/C169同题采用不同指标和权重方式。数学增强：数据区分度不等于业务重要性；排序结果进入后续筛选时，检查筛选是否误删全局可行或更优方案。

## 分类与聚类

先问是否存在可信标签。分类定义目标、样本单位、特征可用时间与误分类代价；聚类定义相似性、尺度和簇数选择，检查簇的稳定性与实际含义。聚类编号不能直接解释为真实类别。

2021/E/E014有分类器比较，E037有聚类/分类分流；2022/C/C155有成分空间处理。正确性增强：同一对象重复测量按组切分；标准化、降维、特征选择只在训练部分拟合；类别不均衡时说明各类错误，不只报总体准确率。

## 统计推断

定义观察单位与抽样结构 → 提出具体关系/假设 → 检查独立性、重复测量、分布和可识别性 → 给模型及误差结构 → 估计参数与不确定性 → 做诊断并按条件解释。

2021/B/B106从实验趋势选择项；2025/C/C023/C132以个体差异解释混合效应结构。正确性增强：报告效果量与区间；不能用显著性代替实际意义，不能把观测相关性写成因果。小样本列联检验必须检查适用条件，不照抄旧稿的判断阈值或校正方法。

## 机理、ODE与PDE

确定系统边界、坐标与状态 → 基于守恒/受力/几何逐项推导 → 初值与外边界 → 多层系统界面条件 → 参数来源与适用近似 → 检查特例/平衡 → 数值离散与误差。

波浪能2022/A/A171按阻尼情况选择解析或数值，A022检查近似成立范围；高温服装补充稿列分层方程与边界。正确性增强：边界通量方向一致；界面需要的连续性条件有物理依据；检查状态变量是否足够，未知参数是否能被观测识别。

## 图论、网络与调度

定义节点/边的实体意义 → 方向、容量、代价和时间 → 可行动作和状态转移 → 证明或检查算法条件 → 输出可执行路径/日程而非仅一个目标值。

2025/D/D037使用动态网络；2022/D/D999从信息下界出发。证据少，场景建议置信度有限。正确性增强：负边权不能直接用普通Dijkstra；时间依赖路径检查FIFO等成立条件，不满足时考虑时间扩展状态；路线在经过时可行，不只是起始时可行。

## 仿真与随机规划

定义随机源及分布依据 → 决策在何时可知哪些信息 → 仿真状态/事件更新 → 设重复次数、种子与指标 → 在独立场景评价 → 给变异、区间与失败率。

2024/B/B195与2024/C/C094提供场景展开例子，不证明其所有统计处理正确。正确性增强：不同场景共享同一先验决策；允许观察后调整时明确补救决策与信息边界；每场景最优收益的平均值通常不是现实可实现的先验策略收益。随机模拟描述模型内结果，不冒充实测数据。
