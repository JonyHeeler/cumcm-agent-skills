# 模型评价

本技能辅助 MathModelAgent 的 5writing 阶段；沿用旧流程的调度、阶段边界、文件交接、章节和验收要求，建模/编码阶段的写作建议先进入阶段报告，正式正文由 `5writing` 落实。也可独立审改已有论文的对应内容，保持现有结构，不启动整套流程。

读取 [评价决策](references/decisions.md)，先定位假设、数据范围、算法取舍和实际验证结论。

1. 每个优势绑定一个具体选择，说明它提供的能力及已有证据。没有测量的效率和精度不要宣称提高。
2. 每个局限绑定被忽略的机制、数据不足、算法限制或使用条件，指出影响哪个答案以及目前能支持的范围。
3. 提出改进时明确需要的新增数据/结构和检验办法，不写“进一步优化”；未实施的改进用未来/条件语气。
4. 发现硬约束违反、数据泄漏、结果矛盾等当前正确性问题时，返回修复，不能把它们包装成普通局限后继续宣称完成。
5. 推广只沿仍成立的机制和条件展开；换领域需要新数据标定或模型修改时说清楚。

输出精简且与证据对应的评价，不强制优缺点数量对称，不为凑数夸大创新。
