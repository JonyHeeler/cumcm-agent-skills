# 评价与边界

证据E01：主集局限相关词58/64，评价段检测到60/64。2021/C/C169 L822把库存递推的作用说清；2024/B/B159 L772指出精确期望方法在复杂工序下的难度；2025/D/D037 L464起把网络规模与计算代价相连。与此同时样本也有“模型准确、普适性强”等证据不足自评，不能因优秀身份照搬。

## 下一句应补什么

- 只有“精度高”：补实际误差、基准、条件；没有数据则删掉精度结论。
- 只有“模型简单”：说明省略了什么、节约了什么，以及代价是否受检验约束。
- 只有“可解释”：指出哪个参数/关系对应现实对象及可用于什么判断。
- 只有“未考虑更多因素”：指出具体因素、影响路径与受影响答案。
- 只有“可推广”：列出必须保留的结构和需要重新估计的参数。

自拟评价示例：若模型用平均温度代替空间温度，“单状态方程便于求解达到目标平均温度的时刻；但不能直接判断池内最低局部温度。若任务要求局部舒适度，需增加分区状态或空间模型，并用多位置温度观测检验。”这说明了功能与边界，不暗示已证明空间均匀。

推广、缺点与错误分开：数据只覆盖一个季节是适用范围限制；未来信息泄漏是应立即修复的验证错误；增加跨季节数据是改进方案。不要把后两者混成“未来有待研究”。
