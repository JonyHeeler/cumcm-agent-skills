# 语义保真而非同义词替换

证据R01：主集重述相关标题62/64；2025/A/A196把前两问合并说明再区分后续任务，2023/D/D039用连续叙述，2021/B/B007用问题提出。背景+任务是可用功能划分，固定二段不是强规律。研究没有原题配对集，未证明压缩率或降重率。

## 压缩决策

保留：使可行域、目标、适用情景或输出形式改变的信息。删除：不参与数学任务的宣传、重复例子和重复解释。精确数值可进入参数表，但正文需明确该表是给定条件，不能把关键限制删得无法找回。

把故事变成任务时显式确定动作：估计哪个未知量、判断什么类别、选择何种策略、优化哪项指标、证明什么条件。不要在重述阶段把“分析关系”擅自改成“建立线性回归”。

自拟保真对照：原题要求“在前30分钟各时刻温度均不低于38℃”；合格压缩为“确定满足30分钟全过程最低温度限制的方案”。写成“使第30分钟温度达到38℃”改变了可行域，必须修正。

自然语言的范围词必须逐一对照：每一与平均、恰好与至少、最多与尽可能少、独立与相关、条件概率与总体概率。题目允许多个情景时保留全部分支，不只改写最容易计算的那一个。
