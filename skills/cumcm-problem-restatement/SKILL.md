# 问题重述

本技能辅助 MathModelAgent 的 2analysis-modeling、5writing 阶段；沿用旧流程的调度、阶段边界、文件交接、章节和验收要求，建模/编码阶段的写作建议先进入阶段报告，正式正文由 `5writing` 落实。也可独立审改已有论文的对应内容，保持现有结构，不启动整套流程。

先读原题相关段落和 [语义保真规则](references/decisions.md)，不要仅凭已有论文转述改写。

1. 抽取对象、输入、输出、条件分支、硬约束、量词、时间范围和单位。
2. 删除不影响这些元素的背景叙事，用自己的语言把每问变成明确任务。背景与任务是两种功能，可分段或分小节，不限定两个自然段。
3. 对照原题检查“至少/至多”“每时刻/终点”“期望/保证”等含义没有变化。不能用“尽量”弱化硬约束。
4. 将选型理由和算法移到问题分析；重述不提前宣布解法或结果。

输出重述正文及简短的内部“题面要求→重述位置”检查记录。数字或条件有歧义时回查原PDF；缺少原题则标明无法完成保真核对，不虚构一致性结论。
