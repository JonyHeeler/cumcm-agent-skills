# 论证与行文

本技能辅助 MathModelAgent 的 5writing 阶段；沿用旧流程的调度、阶段边界、文件交接、章节和验收要求，建模/编码阶段的写作建议先进入阶段报告，正式正文由 `5writing` 落实。也可独立审改已有论文的对应内容，保持现有结构，不启动整套流程。

先读 [修辞决策](references/decisions.md)，辨认待改段落正在定义、推导、选择方法、报告结果还是评价。

1. 保留模型含义和结论强度；发现数学疑点先标明并回查，不用流畅措辞掩盖。
2. 全文贡献可用“本文”，方法选择可用“我们”或无主语结构；数学关系让变量/系统作主语，结果让指标作主语。不要按词频统一替换。
3. 公式前说明要表达什么和为什么；公式后解释新量、条件及用途。后文出现的所有变量都应在符号表中列出，临时辅助量也不例外；修改符号后同步表格。
4. 推理连接词必须有可检查的前提。观察、解释、假设和证明分开，有限实验的结论保留范围限定。
5. 新模型承接旧模型时写清复用和改动。句段过长按逻辑任务分拆，删去没有增加信息的形容词和工具名。

交付精修稿；对会改变含义或需新证据的地方说明原因，不擅自改数字、参数、硬约束或声称已补做实验。
