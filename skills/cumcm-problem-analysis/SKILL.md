# 问题分析

读 [路线选择](references/decisions.md)，以题面和已检查的数据为输入。

1. 明确每问待求对象和已知条件，指出真正阻碍求解的关系或不确定性。
2. 找能将对象数学化的依据：几何、守恒、概率结构、数据特征或决策约束。若还没有依据，先提出需要检查的数据/条件，不直接给算法名称。
3. 有实质选择时比较候选：其成立条件与当前问题是否相符，复杂度增加能否解决当前困难。没有比较就不编写“比较发现”。
4. 选择路线，说明输入怎样变成输出、前问哪些结果可复用，以及准备用什么证据检验答案。
5. 在分析段留下关键直觉或少量必要关系；完整符号、约束组和算法实现交给建模与求解部分。

输出逐问分析和简洁依赖关系。问题独立时不强造层层递进；题型混合时允许一问含多个阶段。
