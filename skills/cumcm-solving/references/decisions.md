# 求解决策与正文深度

证据Q01：主集迭代词35/64、收敛23/64、复杂度18/64、流程图25/64、伪代码4/64。关键词缺失不等于内容缺失，也不形成必须使用的清单。2021/A/A028将步长与任务精度联系；2022/A/A171按模型复杂度采用解析/数值互验；2024/C/C094讨论求解器与贪心的效果/代价。

|算法情形|正文解释到哪里|支撑材料放什么|
|---|---|---|
|标准线性/整数求解器|模型结构、求解器、容差/限时、状态、最优间隙|环境、命令、日志、完整解|
|低维搜索|搜索域、步长/界限、终止、是否全枚举|网格结果、代码|
|自定义迭代|状态定义、更新式或伪代码、停止规则、可行性处理|实现和收敛轨迹|
|启发式改进|为何需改、编码/邻域、约束修复、参数依据、多次运行表现|种子、各次结果、运行预算|
|ODE/PDE|离散方法、初边值实现、时间/空间步长和误差|网格数据、解文件、对照计算|
|统计估计|估计目标/损失、样本划分、选参方法、诊断|数据处理代码、参数输出|

流程图用于复杂分支/状态关系；伪代码用于非显然更新；迭代式用于明确数学递推。选择最能解释关键机制的一种或必要组合，不把三者重复铺满。只有规模影响选择或运行不可接受时，展开复杂度分析。

算法终止与数学收敛不同。达到最大迭代次数只能说明停止；目标稳定不能证明约束满足或全局最优。求解器限时但有可行解时保留该解与界，不隐去未闭合间隙。

自拟对照：若模型只有两个非负整数变量且界限很小，枚举所有可行组合即可提供完整最优性证据。使用遗传算法后多次得到同一方案，证据反而没有变强。

复现记录保持最小充分：输入版本/文件、依赖版本、运行命令、关键参数/种子、实际输出。代码中的单位变换、缺测处理和约束修改必须同步模型文稿。调试日志无需全部进入正文。
