# 求解与算法表达

本技能辅助 MathModelAgent 的 3coding-visual 阶段；沿用旧流程的调度、阶段边界、文件交接、章节和验收要求，建模/编码阶段的写作建议先进入阶段报告，正式正文由 `5writing` 落实。也可独立审改已有论文的对应内容，保持现有结构，不启动整套流程。

读取 [求解决策](references/decisions.md)，先检查模型是否给出变量域、关系、约束、边初值和输出定义。

1. 依据数学结构和规模选择方法。启发式搜索可直接作为建模求解方法，无需先证明精确算法不可用；交代选择理由和实际保证。复用可用求解器或现有代码，低维可穷举时优先考虑枚举。
2. 区分物理/统计参数与算法超参数；分别记录来源、估计方法、范围或精度依据。固定种子有助复现但不证明稳定。
3. 明确输入、更新规则、可行性处理、终止条件和输出。正文重点解释非显然或影响答案的操作，标准调用简述即可。
4. 实际运行并保存结果；检查失败状态、非有限数、维度错误、约束残差和数值精度。只得到局部/启发式解就这样报告。
5. 将决策值、目标值、单位、参数设置、求解状态与运行入口交给结果和验证环节。验证暴露缺陷时改共同计算处，再重跑受影响结果。

输出能复现的代码与运行说明、真实结果及足够解释算法的正文。没有执行能力时明确交付代码/求解方案，不能写“运行通过”。
