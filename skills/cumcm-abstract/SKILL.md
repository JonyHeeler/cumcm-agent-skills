# 摘要

本技能辅助 MathModelAgent 的 5writing 阶段；沿用旧流程的调度、阶段边界、文件交接、章节和验收要求，建模/编码阶段的写作建议先进入阶段报告，正式正文由 `5writing` 落实。也可独立审改已有论文的对应内容，保持现有结构，不启动整套流程。

读取 [摘要的取舍规则](references/decisions.md)，先索取或定位每问的已验证答案和正文依据。

1. 为每问提取“困难—关键方法—答案—可信度边界”。区分实际完成的计算与计划；没有结果不能写“求得”。
2. 先选答案，再选解释答案必需的模型和处理。用模型名称说明它解决什么，不堆砌算法名。
3. 按独立任务或递进关系压缩组织，背景只保留辨认对象所需信息。无需固定背景段或一问一段。
4. 核对核心数字、单位、情景、精度与正文一致。沿用旧摘要要求：数值型子问题必须报告方法与精确的关键数值结果；该数值要求对非数值题默认不生效，后者用关系式、可行条件或证明结论回答，不为凑数编造指标。
5. 只保留最能界定可信度的验证信息；删去库调用、调试过程和无证据的“准确、稳定、创新”。按当前官方版面要求再次压缩。

交付摘要、少量可检索的关键词及内部数字来源清单；来源清单不是摘要正文的一部分。若结果尚缺，明确提供的是摘要提纲或未完成草稿。
