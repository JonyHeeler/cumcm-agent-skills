# 摘要的取舍

证据A01：主集64篇均定位到摘要，57篇命中数字与单位等模式，但其中可能包含题面参数。不能声称这是“摘要关键结果率”。2021/C/C169摘要将建模与具体方案相连；2024/C/C094比较两种算法的结果和代价；2024/A/A053直接从问题一展开。2021/A/A028出现数学式，故不强制无公式。摘要字符中位数1152受转换影响，不作为字数要求。

## 判断下一句写什么

- 读者不知研究对象：补足对象和目标，压缩宏大背景。
- 已有对象但不知道困难：写决定方法选择的结构，如时间耦合、定和、重复测量。
- 只有模型名：说明它输出哪个量，解决哪一问。
- 已有方法但没有答案：从结果账本选可比较的关键数值或数学结论。
- 已有答案但容易误读：补情景、单位、适用范围或是否只是可行解。
- 前问已经解释公共模型：后问只写新增条件和相应结果。

取舍标准是新信息，不是固定句式。大量方案放表或附件，摘要给目标值和代表性决策；不能把唯一答案全部藏进附件。

自拟示例：已知模拟任务结果为“整数方案x=2、y=2、利润14，枚举全部可行组合验证最优”，摘要可写“以两类产量为整数决策量，在工时与材料约束下最大化利润；全可行域枚举得到产量分别为2和2、利润为14。”不写未测量的“算法高效、普适性强”。这些数字仅为技能演练，不用于任何真实赛题。

关键词选问题对象、关键模型、确有核心作用的方法；正文没有用到的方法不进关键词。所有检验数字必须与相同数据划分、情景、单位的正文条目一致。
